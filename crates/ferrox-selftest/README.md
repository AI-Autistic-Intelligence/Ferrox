# 🧪 Ferrox Self-Test (`ferrox-selftest`)

`ferrox-selftest` provides the automated OWASP WSTG security auditor, continuous benchmark suite, and self-testing pipeline for Ferrox applications.

---

## ⚡ Key Features

- 🛡️ **WSTG Auditor (`WstgAuditor`)**: Automatically audits HTTP endpoints against OWASP Web Security Testing Guide rules (Mandatory headers, Server disclosure, Honeypot reaction).
- 📊 **Report Printers**: Terminal color output and Markdown export (`to_markdown`).
- ⏱️ **Continuous Benchmark Suite (`ContinuousBenchmark`)**: Evaluates execution latency, throughput, and memory consumption across all 10 SOTA literature innovations.
